# RepoWise

>A lightweight codebase analysis toolset for visualizing repository architecture and basic health checks.

## Overview

RepoWise provides a small backend (`server`) that fetches a GitHub repository's file tree, filters analyzable files, and returns summary statistics. It includes an `ai-service` (Flask) for future AI-enabled features and a React `client` for visualization and user interaction.

## Features

- Analyze a GitHub repository tree and return basic stats (file counts, issues, README).
- Filter repository files to a focused set of analyzable source files.
- Parse imports across multiple languages to build an architecture graph consumable by a frontend.
- Health endpoints for quick service checks.

## Repository Structure

- `server/` — Express backend that implements repository analysis endpoints and parsing logic.
- `client/` — Vite + React frontend (uses React Query) for UI and visualizations.
- `ai-service/` — Flask app scaffold for future AI features and integrations.

## Key Files

- Server entrypoint: `server/src/index.js`
- Main route: `server/src/routes/repoRoutes.js` (POST `/api/repo/analyze`)
- GitHub helper: `server/src/services/githubService.js`
- Architecture builder: `server/src/services/architectureService.js`
- File filter util: `server/src/utils/fileFilter.js`
- Client entrypoint: `client/src/main.jsx`
- AI service app factory: `ai-service/app/__init__.py`

## Quick Start

Prerequisites:

- Node.js (recommended v18+)
- Python 3.10+ (for `ai-service` if you plan to run it)
- A GitHub Personal Access Token (set `GITHUB_PERSONAL_TOKEN` to increase API limits)

Server

1. Install dependencies:

```bash
cd server
npm install
```

2. Set env var and run:

Windows PowerShell:

```powershell
$env:GITHUB_PERSONAL_TOKEN = "<your_token>"
npm run dev
```

This runs the server (default port 3001). Health: `GET /api/health`.

Client

1. Install and run the dev server:

```bash
cd client
npm install
npm run dev
```

2. Open the Vite preview URL (usually `http://localhost:5173`).

AI Service (optional)

1. Create and activate a virtual environment, then install:

```bash
cd ai-service
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

2. Run the service:

```bash
python run.py
```

The Flask app exposes `GET /health` on port 5000 by default.

## API

- POST `/api/repo/analyze` (server):
  - Body: `{ "url": "https://github.com/owner/repo" }`
  - Returns: JSON summary including `stats`, `sampleFiles`, and `sampleIssues`.

Example curl:

```bash
curl -X POST http://localhost:3001/api/repo/analyze \
  -H "Content-Type: application/json" \
  -d '{"url":"https://github.com/facebook/react"}'
```

## Implementation Notes

- `server/src/services/githubService.js` uses the GitHub REST API to fetch repository trees, file contents, commits, and issues; it respects pagination and caps to avoid excessive calls.
- `server/src/utils/fileFilter.js` contains the list of analyzable file extensions and exclusion patterns.
- `server/src/parsers/*` provide lightweight import extraction per language (e.g., `jsImportParser`), used by `architectureService.js` to build a nodes/edges graph.
